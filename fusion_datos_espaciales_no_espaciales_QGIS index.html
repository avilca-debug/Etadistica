Fusión de datos espaciales y no espaciales en QGIS

Guía práctica para unir una capa espacial GeoPackage (.gpkg) con una tabla CSV mediante el código UBIGEO, verificar la unión y calcular indicadores como área y densidad poblacional.

Objetivos de aprendizaje
  • Diferenciar datos espaciales y no espaciales.
  • Preparar correctamente el campo UBIGEO.
  • Realizar una unión de atributos en QGIS.
  • Detectar problemas de coincidencia.
  • Calcular área en km² y densidad poblacional.

1. Marco teórico

Conceptos básicos necesarios antes de realizar una fusión.

Datos espaciales

Son datos que contienen una geometría asociada a una ubicación geográfica: puntos, líneas o polígonos. En este caso, un archivo .gpkg puede contener los límites de los distritos del Perú.

Datos no espaciales

Son tablas que contienen atributos pero no geometría. Por ejemplo, un archivo .csv con población, pobreza, ingreso o número de viviendas por distrito.

Principio clave: para fusionar ambos archivos debe existir una variable común en las dos tablas. Para datos distritales del Perú, normalmente se utiliza el UBIGEO.

2. Preparación de los archivos

1

Cargar el GeoPackage

En QGIS use Capa → Añadir capa → Añadir capa vectorial. Seleccione el archivo DISTRITO.gpkg.

2

Cargar el archivo CSV

Use Capa → Añadir capa → Añadir capa de texto delimitado. Seleccione el archivo CSV.

Si el CSV no contiene coordenadas, marque la opción equivalente a sin geometría / tabla solamente.

3

Verificar el UBIGEO

El código UBIGEO debe tener el mismo formato en ambos archivos. Para distritos normalmente tiene 6 caracteres.

Problema frecuente: Excel elimina los ceros iniciales. Por ejemplo, 010101 puede convertirse en 10101. En ese caso la unión no encontrará coincidencias.

Cómo corregir UBIGEO en Excel

Si el UBIGEO está en la celda A2, cree una nueva columna y use:

=TEXTO(A2;"000000")

Luego copie la columna y use Pegado especial → Valores, guarde nuevamente como CSV y vuelva a cargarlo en QGIS.

3. Fusión mediante unión de atributos

Este es el procedimiento recomendado desde las propiedades de la capa espacial.

1
Clic derecho sobre la capa DISTRITO → Propiedades.
2
Seleccione la pestaña Uniones.
3
Presione el botón + para agregar una nueva unión.
4
Configure:
  • Capa de unión: archivo CSV.
  • Campo de unión: UBIGEO del CSV.
  • Campo objetivo: UBIGEO de la capa espacial.
5
Pulse Aceptar y abra la tabla de atributos de la capa espacial.
Si la unión fue correcta, en la tabla del GeoPackage aparecerán nuevas columnas provenientes del CSV, por ejemplo población, pobreza u otros indicadores.

4. Verificación de la unión

Comprobar coincidencias

Revise varios distritos conocidos. Las variables del CSV no deben aparecer como NULL si existe un UBIGEO coincidente.

Revisar tipo de dato

Es preferible que ambos campos UBIGEO sean texto. Si uno es entero y el otro texto, pueden producirse problemas de comparación.

Si muchos registros aparecen como NULL, revise: longitud del UBIGEO, ceros iniciales, espacios, duplicados y nombres de campo.

5. Cálculo del área y densidad poblacional

¿Por qué no aparece una columna “área”?

En muchas capas espaciales el área no está almacenada como un atributo visible. QGIS puede calcularla directamente desde la geometría del polígono.

Crear el área en km²

1
Abra la tabla de atributos.
2
Pulse Calculadora de campos.
3
Cree un nuevo campo decimal llamado area_km2.
4
Use la expresión: 
$area / 1000000
Importante: esta fórmula es correcta cuando la capa está en un sistema de coordenadas proyectado cuya unidad es el metro. Si la capa está en coordenadas geográficas (grados), debe reproyectarse antes.

Calcular densidad poblacional

Si la población está en un campo llamado poblacion y ya existe area_km2, cree otro campo decimal: 

"poblacion" / "area_km2"

La unidad resultante será:

habitantes por km².

7. Errores frecuentes

Problema Causa probable Solución
Campos unidos aparecen NULL UBIGEO no coincide Revisar longitud, ceros iniciales y tipo de dato.
Área demasiado pequeña CRS incorrecto o geometría problemática Revisar CRS, reproyectar y validar geometrías.
UBIGEO perdió el cero inicial Excel lo interpretó como número Usar TEXTO(A2;"000000") y guardar como texto.
La tabla CSV no aparece en el mapa No tiene geometría Es normal: se utiliza como tabla para la unión.

10. Conclusiones

  1. La unión de datos espaciales y no espaciales requiere una variable común y consistente.
  2. El UBIGEO es un identificador adecuado para integrar información territorial del Perú.
  3. Los ceros iniciales y el tipo de dato del UBIGEO deben verificarse antes de realizar la unión.
  4. QGIS puede calcular el área directamente desde la geometría, aunque no exista un campo de área en la tabla.
  5. La densidad poblacional se obtiene dividiendo la población entre el área expresada en km².
